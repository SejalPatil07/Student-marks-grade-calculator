# Project Statement

## Project Title
Student Marks & Grade Calculator

## Problem Statement
Calculating a student's total marks, percentage, and grade manually can take time and may lead to calculation errors.

The aim of this project is to develop a simple Python-based system that accepts student information and subject marks, performs the required calculations, and displays the student's academic result in an organized manner.

## Scope
The project focuses on calculating student performance based on the marks entered by the user. It calculates total marks, percentage, grade, and final result.

## Target Users
- Students
- Teachers
- Academic users who need quick result calculations

## High-Level Features
- Enter student details
- Enter subject marks
- Calculate total marks
- Calculate percentage
- Generate grade
- Display pass/fail result
- Display the final result clearly
